Как запустить:

1. Откройте файл "TodoApp.sln" в Visual Studio.
2. Нажмите "F5" для запуска 
3. Чтобы сохранить данные, просто закройте окно программы. Задачи сохранятся в файл "tasks.json".

откройте файл screenshot.png  

Чек-лист:
1)Модель. Классы задачи (TodoItem) и списка задач (TodoList), поля закрыты, изменение только через методы. В модели нет окна и вывода.
2)Окно. Поле ввода, кнопка «Добавить», список задач с отметкой выполнения и дополнительным полем (срок).
3)Операции. Выполнить, переименовать, удалить. Список обновляется сразу.
4)Ошибки. Пустое название, действие без выбранной задачи: сообщение, программа работает дальше. Пустое название запрещено в модели.
5)Сохранение. Задачи сохраняются в JSON и загружаются при запуске. Нет файла: пустой список.

Как устроен проект:
Проект разделен на модель и интерфейс:
"TodoItem.cs" — модель одной задачи. Хранит название, статус выполнения и срок. Инкапсулирует логику проверки названия .
"TodoList.cs" — модель списка задач. Управляет коллекцией задач, умеет сохранять и загружать их из JSON. Реализована фильтрация и сортировка по сроку .
"MainForm.cs" — интерфейс (окно). Отвечает за отображение данных, ловит ошибки модели через "try-catch" и переделывает список при любых изменениях.

Что использовал:
Инкапсуляция: Все поля в моделях (TodoItem, TodoList) закрытые (private), доступ к ним осуществляется только через публичные методы.
Исключения: Модель не знает про окна, поэтому при ошибках (например, пустое название) она дает ошибку.Окно MainForm ловит их через try-catch и показывает MessageBox.
Сериализация JSON: Для сохранения задач используется System.Text.Jso` (методы JsonSerializer.Serialize и Deserialize).
События: Обработчики кликов (btnAdd_Click, btnDelete_Click и другие) привязаны к кнопкам.
