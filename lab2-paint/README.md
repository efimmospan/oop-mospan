Как запустить
1. Откройте файл PaintApp.sln в VS.
2. Нажмите F5 для запуска.

Чек-лист:
1)Окно.Холст, выбор инструмента (прямоугольник, эллипс, линия, карандаш), выбор цвета и толщины.
2)Фигуры. Линия, прямоугольник, эллипс рисуются протягиванием с предпросмотром. Карандаш рисует кривую.
3)Иерархия.Абстрактный класс Shape, у каждой фигуры свой Draw. Рисунок рисуется одним циклом без проверки типа.
4)Отмена и очистка. Кнопка «Отменить» и «Очистить» работают.
5)Файл. Сохранение в JSON и открытие с восстановлением всех фигур, цветов и толщин. Объект нужного класса создает фабрика (shapeFactory).

Как устроен проект:
Проект разделен на модель и интерфейс:
Shape — абстрактный базовый класс. Хранит точки, цвет и толщину. Имеет абстрактные методы Draw и Contains.
RectShape, EllipseShape, LineShape, PencilShape — наследники Shape, реализуют свою логику рисования (полиморфизм).
Drawing — модель рисунка. Хранит список фигур, умеет добавлять, удалять, искать фигуру под курсором, сохранять и загружать в JSON.
ShapeFactory — паттерн Фабрика. По строковому имени класса создает нужную фигуру при загрузке из файла.
ICommand, Commands, History — реализация паттерна Команда для отмены и повтора действий.
MainForm — интерфейс (окно). Обрабатывает клики мыши, выбор инструментов, вызывает методы модели.

Что использовал:
1)Инкапсуляция: Поля в классах фигур закрыты (private или protected set), доступ к ним осуществляется через свойства и методы.
2)Наследование: Базовый класс Shape описывает общее для всех фигур, а классы-наследники (RectShape,EllipseShape и т.д.) добавляют свою специфику.
3)Полиморфизм: В классе Drawing фигуры хранятся в списке List<Shape>. При вызове shape.Draw(g) программа сама понимает, какую фигуру рисовать (прямоугольник или линию), без использования if или switch.
4)Паттерн Фабрика (Factory): Класс ShapeFactory используется для создания объектов фигур по их строковому имени. Это нужно для того, чтобы при загрузке из JSON программа понимала, какой именно класс нужно создать.
5)Паттерн Команда (Command): Каждое действие пользователя (нарисовать, удалить, очистить) обернуто в класс-команду (AddShapeCommand, RemoveShapeCommand, ClearCommand). Это позволяет хранить историю действий и делать отмену (Ctrl+Z) и повтор (Ctrl+Y).
5)Сериализация JSON:Для сохранения и загрузки рисунка используется System.Text.Json. Объекты фигур превращаются в текст и обратно.
6)События мыши и клавиатуры: Обработчики MouseDown, MouseMove, MouseUp и KeyDown используются для взаимодействия с пользователем.
